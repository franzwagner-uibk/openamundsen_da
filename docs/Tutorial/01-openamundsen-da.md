# 1. openAMUNDSEN-DA

## openAMUNDSEN and openAMUNDSEN-DA

**openAMUNDSEN-DA** is a leightweight open source framework for ensemble based snow modelling. It is coupled with the fully distributed snow hydrological open source model **openAMUNDSEN**. openAMUNDSEN-DA provides all functionality from the core model openAMUNDSEN and extends functionality for a particle filter based data assimilation of multiple observation variables.

openANMUNDSEN-DA is a python module delivered as docker image for most useser for conveniant usage. As open source project, developers can fork the repository from GitHub and contribute to the code base.

{: .note }

> For more information about **openAMUNDSEN** visit the [documentation](https://doc.openamundsen.org/) and [GitHub](https://github.com/openamundsen/openamundsen).
