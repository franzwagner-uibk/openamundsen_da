# How to Use
{: .no_toc }

A guided walkthrough of openAMUNDSEN-DA using the bundled Rofental example.
The tutorial is structured as one continuous workflow: understand the framework,
set up the runtime environment, inspect the example data, preprocess observations,
run the model, and inspect the outputs.
